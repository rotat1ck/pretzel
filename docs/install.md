## Запуск проекта

1. Установить .NET 10 - https://dotnet.microsoft.com/ru-ru/download/dotnet/10.0
1. Установить MAUI - `dotnet workload install maui-windows`
1. Запустить сборку проекта - `dotnet build -f net10.0-windows10.0.19041.0`
1. Запустить проект из терминала (опционально) - `.\bin\Debug\net10.0-windows10.0.19041.0\win-x64\Pretzel.App.exe`
